# Build-Rechners; PyInstaller legt eine andere libssl ins Bündel, und die
# fertige App stirbt beim Start mit "Symbol not found: _SSL_get0_group_name".

#
# Dependabot meldet dazu CVE-2026-69247 (Bleichenbacher-Orakel beim Entschlüsseln

# hat für macOS immer noch nur arm64-Räder, und das Projekt ruft nirgends pkcs7
# auf – cryptography kommt nur über msal herein, und die App meldet sich gar
# nicht an. Die Meldungen sind deshalb als „nicht genutzt" geschlossen. Beim
# nächsten Anheben prüfen, ob es wieder ein x86_64-Rad gibt; spätestens wenn
# GitHub die Intel-Runner abschaltet (August 2027), fällt diese Zeile weg.
